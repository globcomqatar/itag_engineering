# Build ITAG-0.3.0 — Drawing, Specification, and Product Revision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the controlled engineering master records that define a product's technical identity and revision history, per roadmap Section 11 — Engineering Drawing, Technical Specification, Product Revision — with released-record immutability, file checksum control, and revision comparison, satisfying Section 11.11's exit gate.

**Architecture:** Extends `itag_engineering` (Builds ITAG-0.1.0 and ITAG-0.2.0 already on `develop`). Follows the same house conventions as Build 0.2.0: DocTypes under `itag_engineering_management/doctype/`, services at the module root, standard Frappe `Workflow` fixtures under `itag_engineering/fixtures/` (not module-folder auto-discovery, per Build 0.2.0 Task 6's confirmed finding), reports under `itag_engineering_management/report/`.

**Tech Stack:** Frappe v15.115.0 / ERPNext v15.117.0, MariaDB, ruff, FrappeTestCase.

## Global Constraints

- Builds on Builds ITAG-0.1.0 and ITAG-0.2.0 (already merged to `develop`): `Engineering Settings`, 16 roles, `response.py`/`exceptions.py`/`logger.py`/`compatibility.py`, Item Code Rule/Reservation, Engineering Item Request + workflow, `eir_service.py`.
- No ERPNext or Frappe core file may be modified.
- **Released Baseline Immutability (roadmap Section 4.2, non-negotiable):** a released engineering record shall not be overwritten. A change creates a new controlled revision.
- Drawing storage (Decision Log #5): ERP attachment only — approved PDF stored as a **private** Frappe file (`Attach` fieldtype with `"private": 1` semantics — the file itself lives in the site's private files area since the DocType has no public-facing route), with a SHA-256 checksum identifying the exact released file. No external DMS/CAD-PDM integration.
- Workflow fixture mechanism (confirmed in Build 0.2.0 Task 6): real Workflow documents live in `itag_engineering/fixtures/*.json`, synced unconditionally by `sync_fixtures()` on every `bench migrate` — NOT auto-discovered from a `workflow/` module folder. Any transition whose `allowed` role can also be the document's `owner` MUST set `allow_self_approval: 1`, or that role can never perform its own transition (per Build 0.2.0 Task 6's confirmed Frappe behavior, `frappe/model/workflow.py`'s `has_approval_access`).
- Any workflow-driven DocType MUST have a server-side `validate()` guard preventing the raw workflow engine from reaching a terminal/released state without the actual side-effect (checksum computed, revision fields populated) having occurred — per Build 0.2.0's final-review finding and fix (`fba776b`/`c694830`), the same class of bug must not recur here for the Drawing/Product Revision "Released" transitions.
- Ruff config: 110-char lines, tabs, double quotes, `py310` target.
- All tests use `frappe.tests.utils.FrappeTestCase` (rolls back once per class, not per method) — batch multiple `db_set()` calls into one dict-form call when touching `Engineering Settings` (per Build 0.1.0's `tabSingles` deadlock mitigation).
- Site under test: `frappedevelopment.localhost`. Bench commands via:
  `docker exec -u frappe frappe-docker_devcontainer-frappe-1 bash -lc "cd /workspace/development/frappe-bench && <command>"`
- Work happens on a new git branch `build-0.3.0-drawing-spec-revision` off `develop` inside `apps/itag_engineering`. Commit after each task. No GitHub remote push.

```python
		drawing = frappe.get_doc(

				"drawing_revision": "A",
				"drawing_title": "Gate Valve Body Assembly",

		).insert()

		frappe.get_doc(
			{
				"doctype": "Engineering Drawing",
				"drawing_number": "DWG-TEST-001",
				"drawing_revision": "A",
				"drawing_title": "Gate Valve Body Assembly",
				"drawing_type": "Assembly",
			}
		).insert()

				{
					"doctype": "Engineering Drawing",
					"drawing_number": "DWG-TEST-001",
					"drawing_revision": "A",
					"drawing_title": "Duplicate Attempt",
					"drawing_type": "Assembly",
				}
			).insert()

	def test_released_drawing_cannot_be_edited(self):
		drawing = frappe.get_doc(
			{
				"doctype": "Engineering Drawing",
				"drawing_number": "DWG-TEST-001",
				"drawing_revision": "A",
				"drawing_title": "Gate Valve Body Assembly",
				"drawing_type": "Assembly",
			}
		).insert()
		frappe.db.set_value(
			"Engineering Drawing",
			drawing.name,
			{"workflow_state": "Released", "release_status": "Released", "file_checksum": "abc123"},
		)
		drawing.reload()
		drawing.drawing_title = "Changed After Release"
		with self.assertRaises(frappe.ValidationError):
			drawing.save()

	def test_released_drawing_can_transition_to_superseded(self):
		drawing = frappe.get_doc(
			{
				"doctype": "Engineering Drawing",
				"drawing_number": "DWG-TEST-001",
				"drawing_revision": "A",
				"drawing_title": "Gate Valve Body Assembly",
				"drawing_type": "Assembly",

		drawing.workflow_state = "Superseded"
		drawing.release_status = "Superseded"

		drawing.save()

		for expected in ("Draft", "Engineering Review", "Checked", "Approved", "Released", "Superseded", "Obsolete"):
```

```python
# Copyright (c) 2026, Globcom Qatar and contributors
# For license information, please see license.txt

import frappe
from frappe import _
from frappe.model.document import Document

RELEASED_STATES = ("Released", "Superseded", "Obsolete")

# Fields a transition INTO Superseded/Obsolete is allowed to change, on top of
# the state fields themselves - everything else must be frozen once Released.
POST_RELEASE_ALLOWED_FIELDS = {"workflow_state", "release_status", "superseded_date", "modified", "modified_by"}


class EngineeringDrawing(Document):
	def validate(self):
		self.validate_immutable_once_released()
		self.validate_file_not_replaced_after_release()

	def validate_immutable_once_released(self):
		if self.is_new():
			return
		before = self.get_doc_before_save()
		if not before or before.release_status not in RELEASED_STATES:
			return
		# Already released (or later): only a transition into Superseded/Obsolete
		# (and the bookkeeping fields that go with it) may still change.
		for fieldname in self.meta.get_valid_columns():
			if fieldname in POST_RELEASE_ALLOWED_FIELDS:
				continue
			if self.get(fieldname) != before.get(fieldname):
				frappe.throw(
					_("{0} cannot be changed once the drawing is Released.").format(
						self.meta.get_label(fieldname)
					)
				)

	def validate_file_not_replaced_after_release(self):
		if self.is_new():
			return
		before = self.get_doc_before_save()
		if not before:
			return
		if before.file_checksum and self.approved_file != before.approved_file:
			frappe.throw(_("The approved file cannot be replaced once a file checksum has been recorded."))
```

```python
"""File checksum computation and validation (roadmap Section 11.7)."""

import hashlib

import frappe


def compute_file_checksum_from_content(content):
	"""SHA-256 hex digest of raw file bytes."""
	return hashlib.sha256(content).hexdigest()


def validate_checksum(content, expected_checksum):
	return compute_file_checksum_from_content(content) == expected_checksum


def get_file_content(file_url):
	"""Read a Frappe-managed (private or public) file's raw bytes given its
	file_url, using the standard File doctype resolution so this works
	regardless of the underlying storage path."""
	file_doc = frappe.get_doc("File", {"file_url": file_url})
	return file_doc.get_content()


def sync_drawing_checksum(doc, method=None):
	"""doc_events before_save hook for Engineering Drawing (wired in hooks.py).
	Populates file_checksum from the approved_file's content whenever a file
	is attached and no checksum has been recorded yet - never overwrites an
	existing checksum (that would defeat its purpose once Released; Engineering
	Drawing's own validate() separately blocks replacing the file after a
	checksum exists at all, released or not)."""
	if doc.doctype != "Engineering Drawing":
		return
	if doc.approved_file and not doc.file_checksum:
		content = get_file_content(doc.approved_file)
		doc.file_checksum = compute_file_checksum_from_content(content)
```

```python
"""Drawing revision creation and comparison service (roadmap Section 11.8)."""

import frappe
from frappe import _

BOOKKEEPING_FIELDS = {
	"name",
	"owner",
	"creation",
	"modified",
	"modified_by",
	"idx",
	"docstatus",
	"workflow_state",
	"release_status",
	"drawing_revision",
	"file_checksum",
	"approved_file",
	"revision_date",
	"effective_date",
	"superseded_date",
}

CARRY_FORWARD_FIELDS = ("related_item", "product_family", "applicable_standard", "security_classification")


def _latest_revision_doc(drawing_number):
	rows = frappe.get_all(
		"Engineering Drawing",
		filters={"drawing_number": drawing_number},
		fields=["name"],
		order_by="creation desc",
		limit=1,
	)
	if not rows:
		return None
	return frappe.get_doc("Engineering Drawing", rows[0].name)


def create_new_drawing_revision(drawing_number, new_revision, **fields):
	source = _latest_revision_doc(drawing_number)
	if not source or source.release_status != "Released":
		frappe.throw(_("A new revision can only be created from a Released drawing."))

	new_fields = {
		"doctype": "Engineering Drawing",
		"drawing_number": drawing_number,
		"drawing_revision": new_revision,
	}
	for fieldname in CARRY_FORWARD_FIELDS:
		new_fields[fieldname] = source.get(fieldname)
	new_fields.update(fields)

	return frappe.get_doc(new_fields).insert()


def compare_drawing_revisions(drawing_number, revision_a, revision_b):
	name_a = f"{drawing_number}-{revision_a}"
	name_b = f"{drawing_number}-{revision_b}"
	doc_a = frappe.get_doc("Engineering Drawing", name_a).as_dict()
	doc_b = frappe.get_doc("Engineering Drawing", name_b).as_dict()

	diff = {}
	for fieldname in doc_b:
		if fieldname in BOOKKEEPING_FIELDS:
			continue
		if doc_a.get(fieldname) != doc_b.get(fieldname):
			diff[fieldname] = {"from": doc_a.get(fieldname), "to": doc_b.get(fieldname)}
	return diff


def retrieve_released_drawing_metadata(drawing_number):
	rows = frappe.get_all(
		"Engineering Drawing",
		filters={"drawing_number": drawing_number, "release_status": "Released"},
		fields=["name"],
		order_by="creation desc",
		limit=1,
	)
```

```python
# Copyright (c) 2026, Globcom Qatar and contributors
# For license information, please see license.txt

import frappe
from frappe import _
from frappe.model.document import Document

RELEASED_STATES = ("Released", "Superseded", "Obsolete")
POST_RELEASE_ALLOWED_FIELDS = {
	"workflow_state",
	"revision_status",
	"superseding_revision",
	"modified",
	"modified_by",
}


class ProductRevision(Document):
	def validate(self):
		self.validate_drawing_is_released()
		self.validate_immutable_once_released()

	def validate_drawing_is_released(self):
		if not self.drawing_revision:
			return
		status = frappe.db.get_value("Engineering Drawing", self.drawing_revision, "release_status")
		if status != "Released":
			frappe.throw(_("Product Revision cannot reference an unreleased Engineering Drawing."))

	def validate_immutable_once_released(self):
		if self.is_new():
			return
		before = self.get_doc_before_save()
		if not before or before.revision_status not in RELEASED_STATES:
			return
		for fieldname in self.meta.get_valid_columns():
			if fieldname in POST_RELEASE_ALLOWED_FIELDS:
				continue
			if self.get(fieldname) != before.get(fieldname):
				frappe.throw(
					_("{0} cannot be changed once the Product Revision is Released.").format(
						self.meta.get_label(fieldname)
					)
				)
```

```python
			"revision_status": "Released",
			"effective_from": ["<=", today()],
		},
		fields=["name"],
		order_by="effective_from desc",
		limit=1,
	)
	if not rows:
		return None
	return frappe.get_doc("Product Revision", rows[0].name).as_dict()


def supersede_revision(old_revision_name, new_revision_name):
	if not frappe.db.exists("Product Revision", old_revision_name):
		frappe.throw(_("Product Revision {0} does not exist.").format(old_revision_name))
	if not frappe.db.exists("Product Revision", new_revision_name):
		frappe.throw(_("Product Revision {0} does not exist.").format(new_revision_name))

	frappe.db.set_value(
		"Product Revision",
		old_revision_name,
		{"superseding_revision": new_revision_name, "workflow_state": "Superseded", "revision_status": "Superseded"},
	)
	if not frappe.db.get_value("Product Revision", new_revision_name, "previous_revision"):
		frappe.db.set_value("Product Revision", new_revision_name, "previous_revision", old_revision_name)


def compare_product_revisions(item, revision_number_a, revision_number_b):
	name_a = f"{item}-PR-{revision_number_a}"
	name_b = f"{item}-PR-{revision_number_b}"
	doc_a = frappe.get_doc("Product Revision", name_a).as_dict()
	doc_b = frappe.get_doc("Product Revision", name_b).as_dict()

	diff = {}
	for fieldname in doc_b:
		if fieldname in BOOKKEEPING_FIELDS:
			continue
		if doc_a.get(fieldname) != doc_b.get(fieldname):
			diff[fieldname] = {"from": doc_a.get(fieldname), "to": doc_b.get(fieldname)}
	return diff
```
